Carry design (crates/articul-cli/src/synth.rs, no source comments added)
--------------------------------------------------------------------------
Two persistent filter objects live across the whole utterance inside
render_units, one per stream:
- cascade_live: Option<CascadeFilter> (synth.rs:865), parallel_live:
  Option<ParallelFilter> (synth.rs:866).
Per-segment retune INSTEAD of fresh construction, extending the filter_glide
retune pattern (synth.rs:200-252, CascadeFilter::retune at
crates/articul-dsp/src/cascade.rs:138, ParallelFilter::retune at
crates/articul-dsp/src/parallel.rs:39):
- Single Cascade (synth.rs:927-936): first segment constructs from spec pairs;
  every later Cascade segment calls cascade_live.retune(pairs, sr), which keeps
  y1/y2 resonator state and only swaps coefficients. Filtering steps sample by
  sample through the live object via an FnMut closure into render_unit
  (render_unit signature changed synth.rs:443-451 from &dyn Fn to
  &mut dyn FnMut; no excitation/gain/envelope change).
- Single Parallel (synth.rs:938-948): same pattern on parallel_live with
  triples. Same-length retune preserves branch state; differing branch count
  (1 vs 2 across fricative places) takes ParallelFilter::retune's fresh-branch
  path, i.e. a scoped reset only where arities differ.
- Merged GOAT diphthong (DiphthongJob.live field synth.rs:541; pre-create
  synth.rs:883-885; pass-through synth.rs:886-897; consume synth.rs:576-592):
  live cascade is pre-created from start when absent, retuned to start on entry
  (state kept), then per-sample lerp_pairs(start, end, t) + step exactly as
  before. Post-diphthong state (end coefficients + rung-up y1/y2) is retained
  in cascade_live for the following segment.
Stream switching cascade<->parallel: each stream keeps its own independent
continuous state; switching streams retunes the target stream's live object but
never touches the other stream's stored state. Pause units: carried through
(zero input steps the live filter, yielding a short natural decay tail, then
silence); pause/gain/fade/leveler/tamer/ceiling/crossfade/envelope logic
untouched. Excitation phase-0 restarts KEPT (no source.rs change).
Notch/lateral-zero post-filters: LEFT UNTOUCHED (fresh NotchFilter::new per
segment, synth.rs:950-957 and diphthong synth.rs:593-600). NotchFilter exposes
no retune API, so carry does not fall out of the same pattern trivially; per
task allowance they stay fresh. Stated here explicitly.
