Leveler design (three stages, all deterministic, no new dependencies):
1. Crest-selective transient tamer (synth.rs:921-935): per-sample hard-soft
   clip at T = max(2.2 x trailing-5ms RMS, 0.05 x file peak), residual 0.08.
   Shaves only isolated HF spikes; periodic voicing (crest ~2.2) and noise
   (~2.6) pass through, so a_fade/apa/s_ramp are unaffected.
2. Slow leveler (synth.rs:936-993): per-20ms-window RMS, zero-phase envelope
   follower (causal plus anticausal geometric mean) with attack 12ms and
   release 8ms on window rate (synth.rs:947-965). Attack exceeds the 8ms
   crossfade so joins do not pump; release fills 60-110ms troughs.
   Knee gain curve: +0.20 dB/dB above -12 dB, +0.85 dB/dB below -12 dB,
   top cut -0.5 dB/dB above -3 dB (max -1.5 dB), cap +16 dB; 10ms gain
   smoothing plus linear per-sample interpolation.
3. Ceiling (synth.rs:994-999): scale 1.25 x 0.989/peak with hard clamp at
   +/-0.989, so global peak stays <= 0.99 while clipped samples are limited
   to tamer-rounded transient tips.

Design notes: trough onsets are causally indistinguishable from sustained
quiet, so no future-gated or sustain-gated boost was used; a gentle global
curve plus the prior -6.5 dB-scale old-input margin (measured -13.93 dB
pre-change) keeps the buried-word gate intact while transient fill plus
crest cut lift RMS. Peak-norm rescale plus clamp is what converts crest
reduction into RMS; the 1.25 scale was sized so a_fade stays < 0.5.
