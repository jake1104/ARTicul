Method
------
1. probe/0.0.0.24.1/plandump/ (throwaway cargo bin, path-deps on workspace
   crates, engine untouched) dumps the front-end plan via the REAL engine
   functions: normalize / parse_utterance / plan_utterance(rate 1.0,
   pitch_scale 1.0, base_f0 120.0) and articul_cli::segment_gain_db.
   Boundary sample positions replicate the engine concat arithmetic exactly
   (GOAT merge length, VV->1102 / else->176 fades, per-boundary clamps);
   predicted total lengths match the wav lengths EXACTLY (9792/17446/14666),
   so positions are sample-exact. Full dump: plan.txt in this folder.
2. probe/0.0.0.24.1/junctions.py (stdlib only) measures, per boundary, the
   MFCC euclidean distance (13 coeffs c1..c13, c0 excluded; pre-emph 0.97,
   20 ms Hamming, 512-pt DFT, 26 mel filters 0-11.025 kHz, log, DCT-II)
   between 20 ms windows on each side of the blend zone (nose-to-nose, the
   zone itself excluded), plus the realised broadband RMS step between the
   same windows (post-leveler, i.e. what the listener gets), plus interior
   controls (adjacent 20 ms window pairs on a 40 ms grid, kept >=1 window
   away from any blend zone).
3. Gain steps are engine-exact (segment_gain_db deltas). F0 steps are
   engine-exact (12*log2(f0_start_next / f0_end_prev) from the plan).

(d) filter-state reset: what the code does per boundary type (read-only)
-------------------------------------------------------------------------
- Every Single segment renders through a FRESH filter: synth.rs:805-830
  (CascadeFilter::from_pairs / ParallelFilter::from_pairs constructed new
  per segment inside render_units, then render_unit closure). No filter
  object is ever carried across a boundary.
- CASCADE-*-GLIDE (can_glide true, synth.rs:192-198; dispatch 645-654):
  filter_glide (synth.rs:200-250) builds a fresh filter from the `from`
  spec, warms it by replaying all n tail samples through it (217-220 for
  cascade, 228-236 for parallel), then steps the raw-signal mix through
  per-sample retuned coefficients (221-225 / 232-235); nasal notch warmed
  the same way (242-249). So state carry is APPROXIMATE (replay, not true
  continuous state), over n = 176 samples here (8 ms). 16 of 21 boundaries.
- MIXED-LINEAR (can_glide false, synth.rs:655-661): pure linear crossfade
  of the two independently-filtered shaped signals over 176 samples. No
  filtering continuity at all; the two sides never share a filter. 4 of 21
  boundaries (all /s/ in-/out-boundaries: annyeong b8/b9, yeobo b4/b5).
- GOAT-EDGE (synth.rs:701-728 work-unit merge; 543-600 render_diphthong):
  no boundary inside o+U (single continuous filter, per-sample retune
  575-581, interpolated gain 590-593). The EDGE entries/exits (hello b3
  l->o) are plain 8 ms zones with a 6.0 dB scalar step. 1 of 21.
- VV-GLIDE 50 ms (synth.rs:845-852 fades; 1102-sample path): exists in
  code but is NEVER exercised: 0 of 21 boundaries (the only VV pair is
  GOAT-merged). All "glide" boundaries here are the 8 ms replay variant.
- Excitation: EVERY generate_* path starts at phase 0.0 (source.rs:34,
  72, 117, 169, 220, 273, 317). Voiced excitation restarts at phase 0 at
  every segment start regardless of boundary type; per-segment F0 glides
  are phase-continuous only WITHIN the segment.
- Post-hoc confound: the causal leveler (synth.rs:908+, 80 ms release per
  0.0.0.23.2) rides on top and roughly halves most scalar steps (e.g.
  planned 9.0 -> realised -5.2 at annyeong b1), but tracks some steps
  nearly 1:1 (yeobo b6: planned 7.0 -> realised -7.3).

Verdict: single winner -> gain smoothing is the 0.0.0.24.2 direction
---------------------------------------------------------------------
- F0 is out (measured zero everywhere). Crossfade length is out (8 ms is
  adequate per 0.0.0.15.4; lengthening risks smear; the 50 ms VV path is
  unexercised so there is nothing to tune there).
- Spectral-jump smoothing is contraindicated: the biggest MFCC numbers are
  phonetic contrast at /s/ boundaries, and the safe fix must not smear
  spectral detail.
- Gain smoothing (raised-cosine scalar interpolation across boundaries,
  the 0.0.0.24.2 leading candidate) is CONFIRMED: up to 9.0 dB planned
  steps, 9/21 >= 5 dB across all three demos incl. 6.0 dB at the hello
  diphthong entry (flagship demo, most-listened transition), realised
  scalar-driven cliffs to -7.3 dB surviving the leveler 1:1. A scalar
  envelope interpolation cannot smear spectra, fits inside every segment
  (shortest segment 41 ms = 904 samples > 441+176 sample margins), and is
  crisply gateable (boundary-step TDD gate). It is also consistent with
  the existing GOAT-internal gain interpolation (synth.rs:590-593):
  extend the same idea across boundaries.
- Documented runner-up (NOT this task): filter-state/excitation carry for
  the s->e cliffs (-17.5/-14.6 dB realised at 0.0/4.0 dB planned gain) and
  the same-gain MFCC residual (<= 11.5). That fix spans filter transplant
  across topologies + phase continuity + envelope interplay: a later
  cascade, not a single fix. It must also respect the 0.0.0.15.4 smear
  constraint at fricatives.
