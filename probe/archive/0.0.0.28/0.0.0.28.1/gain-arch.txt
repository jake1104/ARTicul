0.0.0.28.1 gain-architecture probe: source-table spread vs leveler makeup
================================================================================
READ-ONLY probe — no engine source/config/demo/todo/README edits. New files only
under probe/0.0.0.28.1/ (+ logs/0.0.0.28.1/probe.log). Engine code was linked
read-only by two throwaway probe binaries (plandump, f32dump) and reverted by

Method
------
1. Planned gains: probe binary calls articul_cli::segment_gain_db per segment for
   all 6 eval-corpus items + 3 demos + old input ("hE l@U); probe-side arm
   decomposition (base/declination/final/floor) asserted equal to the engine
   value on all 50 segments (50/50 match=OK, plan.txt).
2. Renders: release articul.exe, fresh, into probe/0.0.0.28.1/. Byte-identical to
   shipped demos (fc /b, sizes 19628/34936/29376 = 9792/17446/14666 samples);
   fixed_sentence sha 2ad4f841 == pinned hash 2AD4 (current tree confirmed).
3. Leveler: exact float64 port of level_output (tamer 5ms ring; 20ms windows;
   causal-only follower atk 12ms / rel 8ms; knee -0.2x above -12dB,
   2.4-0.85x below, extra -0.5x above -3dB; cap +16dB; 10ms gain smoothing;
   per-sample interp; prescale 1.25*0.989/max + clamp +-0.989). Pre-leveler
   signal recovered by per-sample fixed-point inversion; forward residual on
   unclamped samples <= 1.4e-4 (pause_probe 8e-4: silence-zero guard).
   Cross-check: f32 renders via render_sentence (f32dump, no i16 quantization)
   reproduce wav-based spark peaks to <= 1e-4; BASE sim (zero deltas) reproduces
   production spark peaks to 5e-5 (hello s1 0.9481 vs 0.948047).
4. Proposal: per-segment deltas applied to recovered pre (output-domain ownership,
   linear crossfade across fade zones; GOAT internal edge sharp; +-20ms
   smoothing reshape neglected, bounded err ~0.5dB at step edges), forward
   through parametrized replica (cap_db, prescale). Cap x prescale grid measured.

REFINED MECHANISM (replaces the task hypothesis): at every spark window the
makeup gain is ~0dB or negative (hello s1 -0.76dB, s2 +1.10dB, s3 +1.33dB;
annyeong s9 -0.87dB; yeobo s5 -0.36dB; pre-leveler content estimates 0.84-1.18,
i.e. already hot). The global max sample sits INSIDE the worst windows
(hello max pos 1583 in s1 [1544,1764): h-burst tail, E-onset only 0.52;
annyeong max 13327 just before s9 [13366,..): /s/ body; yeobo max 7229 in /s/
group 4; fixed/cluster maxes in /s/ groups). So sparks are peak-anchored:
G pins the max to clamp and runner-ups 0.2-2dB below it read as sparks. The
leveler is not lifting boundary content into the clamp at these windows; the
1.25x prescale is. Within-burst runner-up ratios are gain-invariant (same
segment shape, G renormalizes), which bounds what any table change can do
(see 5).
