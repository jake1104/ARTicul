  renders solo "la (stressed onset) and asserts 2-3 kHz notch depth >= 6 dB

- Metric: raw (unsmoothed) Hann periodogram, N_FFT 8192; depth =
  median(2000-2300 Hz) minus median(2470-2530 Hz). Both bands sit inside
  2-3 kHz. Rationale: the cascade F2 (1400) / F3 (2800) poles leave a wide
  natural valley, so wide flank-vs-valley medians already read 13-16 dB at
  baseline (false positive on the first draft, which passed without the
  zero). The narrow core-vs-edge contrast is negative at baseline and flips
  only when a narrow zero is carved at 2500 Hz. Smoothed spectra dilute the
  300 Hz notch (smoothing smears filtered energy back into the valley), so
  the depth metric deliberately uses the raw periodogram; F1/F2 peak checks
  keep the proven +-12-bin smoothed spectrum from clear_l.
