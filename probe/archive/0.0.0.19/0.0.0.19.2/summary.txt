Task 0.0.0.19.2 GOAT diphthong as one gliding syllable

Merge mechanism (synth.rs only, no front-end plan change)
- Detection: is_goat_pair (synth.rs:99) matches adjacent units where the
  first is a stressed rounded vowel with base_symbol "o" (is_goat_onset,
  synth.rs:85) and the second is an unstressed vowel with base_symbol "U"
  (is_goat_offglide, synth.rs:92). Pause units are excluded. Only this
  pattern merges; every other sequence renders exactly as before.
- Work list: render_units (synth.rs:600) folds a matched pair into one
  WorkUnit::Merged item (synth.rs:580) carrying first/second original
  indices, a merged ProsodicPhoneme (o phoneme, summed duration,
  f0_hz from o, f0_end_hz from U, o stress), and fixed cascade endpoints
  from diphthong_pairs (synth.rs:105): start F1 500 / F2 900, end F1 400 /
  F2 1100, F3 carried from o, upper three formants unchanged.
- Rendering: render_diphthong via DiphthongJob (synth.rs:463/475)
  synthesizes one excitation across the merged span, filters it with a
  per-sample retuned CascadeFilter linearly interpolated start to end
  across the whole span, and applies gain linearly interpolated between
  the two units original segment_gain_db values (original indices kept,
  so endpoint gains are unchanged). The merged spec entry is the cascade
  start pairs, so neighbor crossfades still apply. The o+U internal
  50 ms overlap is absorbed, so output grows by exactly that overlap
  (hello 8248 to 9351 samples).
- Fade cap: the final fade for a trailing merged item is capped by the
  offglide (second) duration (synth.rs final_len branch), so the fade
  never reaches back into the stressed nucleus portion. This preserves
  the 0.0.0.18.2 intent and keeps halves within gate.

F0 staging
- Planned values for hE "loU at base 120 Hz: o f0_hz 155.55 Hz (H*
  nucleus), U f0_end_hz 80.09 Hz (final -7 st). The merged span opens at
  the H* peak value and completes the 155 to 80 Hz nuclear fall inside
  the single glide; no fall energy straddles a segment split.
- Contour: exponential approach f(t) = f_end + (f_start - f_end) *
  exp(-t/tau) with tau = span/4, via new GlottalSource methods
  generate_exp_glide (source.rs:145) and generate_cf0_exp_glide
  (source.rs:196). The fall reaches within about 2 Hz of the 80 Hz
  target by span end and the final third of the glide holds an
  essentially flat low tail. A full-span raised-cosine sweep was measured
  at 0.46 to 0.58 final-80ms autocorr on this signal (sweep smears the
  single-lag correlation of the harmonic-rich tail); the front-loaded
  fall with flat tail measures 0.77.

Creak-skip rule
- render_unit creak condition (synth.rs:425-429) now also requires NOT
  (final unit under 100 ms following a GOAT onset). The merged GOAT span
  itself never takes the creak path (render_diphthong has no creak
  branch). In hE "loU the final U is 83 ms after stressed o, so the old
  code applied generate_creak to the tail; the new code renders periodic
  excitation through the glide end.
