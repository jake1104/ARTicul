## Notes and non-recommendations

- Spectral tilt TL is listed under gap 3 (shared implementation with OQ dynamics).
- Tracheal pole-zero pair (KlattGrid FNP-analogous tracheal formants, Klatt & Klatt 1990) was considered; effect is second-order vs gap 4 and shares its code path — fold in when doing gap 4.
- Segmental duration (Klatt 1979 rules) is substantially landed (intrinsic table, stress/voicing context, final lengthening, cluster shortening); remaining delta (rate-dependent VOT scaling) is small — not ranked.
- Coarticulation beyond locus pull (F1/F3 transitions, rounding spread) is real but lower impact than gaps 1–4 now that locus-equation F2 is in; defer.
- Single most impactful recommendation: gap 1 (mixed excitation for voiced fricatives), because it restores a phonemic contrast with a localized change in one function.
