Method (probe/0.0.0.23.1/breathing_probe.py): each trough split into 20 ms
sub-windows; per sub-window Hann DFT, speech-band (300-3400 Hz) RMS and HF
(4k+ Hz) RMS derived from band power fractions x total RMS; Pearson r of
HF-RMS vs total-RMS across sub-windows. Makeup gain estimated by proxy only:
code inspection (synth.rs:908-999 level_output) shows gain is NOT inferable
without code changes - transient tamer mutates the waveform before the
envelope follower, and applied gain = knee(zero-phase geometric-mean
causal+anticausal follower) + 10 ms smoothing + per-sample interpolation +
global 1.25x scale/clamp; no pre/post pair or bypass flag is exposed, so no
observable ratio isolates makeup gain. Proxy per task spec: HF-RMS/total-RMS
correlation (high r = noise rides the same envelope = breathing signature).
